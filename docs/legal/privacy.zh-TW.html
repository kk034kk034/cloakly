Cloakly 手機版隱私權政策

生效日：2026-10-26

本政策適用於 App Store 與 Google Play 上的 Cloakly 手機版（iOS／Android，套件識別碼 com.cloud52.cloakly）。電腦版若改用你自己的 API 金鑰，資料會直接送到你選擇的服務，不在本政策範圍。

產品是什麼，以及錄音同意

Cloakly 是顯示在畫面上的會議助手。它不是隱藏視窗，也不是用來在面試或考試中作弊的工具。麥克風只在你按下開始會議之後使用。

開始錄音前，你必須先告知並取得其他參與者的同意，並遵守適用法律。我們無法代替你取得同意，也不會驗證你是否已經取得。

Cloakly 的程式沒有呼叫定位、通訊錄、相簿或相機，也沒有廣告識別碼、分析或當機回報 SDK。iOS 內含的檔案選擇套件仍把相簿、相機與音樂選擇程式編進 App，所以系統要求對應的用途說明；這個 App 只會請你選資料夾，不會開啟那些畫面。會議內容若碰巧談到健康或其他敏感話題，那是你錄進去的使用者內容，我們沒有另外做健康資料功能。

iOS 開啟了檔案分享。解鎖後，「檔案」App 可以看見 App 文件目錄，裡面可能有錄音與 cloakly.db。這是讓你自己取出檔案，不是上傳給我們。

免費額度實際規則

免費帳號每個 UTC 日合計最多 1,800 秒（30 分鐘）轉寫，專案問答與計畫建議各最多 5 次。Cloakly Pro 不計入這些每日上限。無論是否為 Pro，單一段即時轉寫的上限都是 30 分鐘。另外還有全體免費用戶共享的每日容量；這是營運限制，不是廣告設定。

第三方

下列服務會在提供功能時處理資料。送審前請再讀一次他們當時的條款，並把與本頁不符的地方改掉。

  • Supabase：帳號、資料庫、Edge Functions。函式在記憶體中處理文字並回傳結果，不把逐字稿寫進資料表。失敗時，程式可能把供應商的錯誤回應寫進函式日誌。這些日誌會保留一段有限期間；天數依 Supabase 當時的方案與設定，本政策不另行指定。連線日誌可能含 IP；我們的資料表沒有 IP 欄位，也不會用 IP 推斷位置。
  • Soniox（隱私權政策、安全說明）：即時轉寫。後端用長效金鑰向 api.soniox.com 換一枚約 60 秒、單次使用的短效金鑰，手機再用它連上 WebSocket。依 2026-10-26 讀到的公開文件，即時請求是短暫處理、不用客戶內容訓練模型，營運日誌不含原始音訊或逐字稿，但用量紀錄可以包含 client_reference_id。Cloakly 沒有呼叫會保存音檔的 Async API。若這段與 Soniox 最新條款不同，以最新條款為準並更新本頁。
  • OpenAI：只在你使用回答建議、會議紀錄、專案問答或計畫建議時，由後端呼叫 https://api.openai.com/v1/chat/completions。預設模型是 gpt-4o-mini，可由伺服器環境變數 OPENAI_CHAT_MODEL 覆寫。送出的是文字，不是音訊。Cloakly 沒有把內容送給其他大型語言模型。依 OpenAI 公開的 API 資料控制說明，經 API 送出的內容預設不會用來訓練或改進其模型，除非客戶明確選擇加入；濫用監控日誌可能包含提示與回應，對這個端點預設最多保留 30 天，法律要求或為防止損害而合理必要時可能更久。此程式沒有送出訓練加入，也沒有申請零資料保留。若 OpenAI 的政策或專案設定與此不同，以其當時政策為準。
  • RevenueCat（隱私權政策）：購買、恢復購買與權益。我們會設定 App User ID 與 Email。刪除帳號時會盡力呼叫 RevenueCat 刪除顧客；金鑰未設定或呼叫失敗時，Supabase 帳號仍會刪除，RevenueCat 側的資料可能留下。
  • Apple 與 Google：商店發行、付款、訂閱管理，以及你若同意提供給開發者的當機報告。卡號由商店處理。

我們不出售個人資料，也不用這些資料做跨 App 廣告追蹤。

保存與刪除

  • 手機上的會議、逐字稿、筆記、專案索引與錄音，在你刪除 App 或清除 App 資料之前會留著。App 內刪除帳號不會清掉這些本機資料。
  • 刪除帳號會要求你重新輸入密碼，並呼叫 delete-account。它會核對 Email，盡力刪除 RevenueCat 顧客，把當天免費用量記成 Email 雜湊，刪掉 webhook 事件裡含有你的使用者 ID 的紀錄，再刪除 Supabase 使用者。帳號相關資料表對使用者設有 cascade，會一併刪除。
  • free_device_claims 沒有連到使用者的外鍵。刪除帳號不會刪掉該列。留下的是裝置識別的 SHA-256、UTC 日期，以及已經刪掉的使用者 ID。
  • 過期（UTC 日期已過）的 Email 雜湊額度列，會在之後任何一次帳號刪除或註冊時清掉。當天的列會留到該日之後的下一次刪除或註冊。
  • 商店訂閱不會因為刪除 Cloakly 帳號而取消，也不會自動退款。請到 App Store 或 Google Play 取消。
  • Soniox、OpenAI、RevenueCat、Supabase 與商店各自的備份或日誌，不由這個 App 直接刪除。能刪的範圍以上列實作為準。

安全

與 Supabase、Soniox、OpenAI、RevenueCat 的連線使用 TLS（HTTPS 或 WSS）。手機上的 SQLite 沒有再加密。請使用裝置螢幕鎖。我們無法保證傳輸或儲存絕對不被入侵。

兒童

本服務不是為兒童設計。你必須年滿 13 歲才能建立帳號。我們不會明知而向未滿 13 歲的人收集帳號資料。

國際傳輸

Supabase、Soniox、OpenAI、RevenueCat、Apple 與 Google 可能在台灣以外、以及你所在國家以外，於各該供應商營運的資料中心處理資料。本政策不指定 Supabase 的區域，因為儲存庫裡的專案設定沒有記載區域。其他服務的機房位置依各該供應商當時的文件。

你的請求

你可以用 App 內功能刪除帳號。若要存取、更正，或無法登入而仍要刪除，請從帳號使用的 Email 寄信到 contact@cloud-52.com。伺服器上沒有逐字稿檔案可匯出；逐字稿在你的手機上。我們沒有另外做一套線上個資申請入口。
